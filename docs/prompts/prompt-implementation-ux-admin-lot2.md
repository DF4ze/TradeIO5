### 2.2 Client Kraken (`service.execution.exchange`)
- `KrakenSpotOrderClient implements SpotOrderPort` (`provider() = KRAKEN`, `@Component @Conditional(LiveExecutionCondition.class)` comme OKX) :
  - `submit` : `AddOrder` limit IOC, `volume` en base, `price` plafond, identifiant client = `clOrdId` interne (`t5…`, ≤ 32, alphanumérique) mappé sur le champ confirmé en doc ; réponse → `OrderAck(clOrdId, txid)` ;
  - `query` : `QueryOrders` par identifiant client (sinon txid) → `OrderState` (statuts Kraken → `OrderPhase` ; IOC partiellement rempli = `CANCELED` terminal avec `accFillSz`) ; ordre introuvable ⇒ `OrderNotFoundException` ;
  - `cancel` : `CancelOrder` ; `fills` : trades de l'ordre → `Fill` (frais **positifs**, `feeCcy` = devise réelle du frais ; tradeId = id du trade Kraken, base de l'idempotence `FillRecorder` `<PROVIDER>:<tradeId>`).
- Mapping d'erreurs identique à OKX : `EOrder:*` ⇒ `OrderRejectedException(code)` ; `EAPI:Invalid key`, `EGeneral:Permission denied`, restriction IP ⇒ `TradeCredentialRejectedException` ; réseau, timeout, `EService:*`, `EAPI:Invalid nonce`, réponse illisible ⇒ `ExchangeUnavailableException` (issue inconnue, **jamais de renvoi**). Espacement minimal entre appels (rate limit). Aucun secret dans log, exception, DTO.
- **Signature et nonce** : extraire la signature HMAC-SHA512 de `KrakenApiClient.privatePost` dans un composant partagé `KrakenSignedRequests` (package `service.connector.apiclient`, comme `OkxSignedRequests` : il signe et envoie, ne connaît aucun ordre) utilisé par le client de lecture **et** le client d'ordres ; **nonce strictement croissant par clé** (`AtomicLong` par empreinte de la clé API — jamais la clé en clair comme clé de map — `max(now, dernier+1)`), thread-safe ; `KrakenApiClient` garde son comportement (tests existants verts) et `ConnectorNoOrderMethodTest` reste vert.
- `ExecutionOrderArchitectureTest` : le test « bean client absent par défaut / présent si LIVE+déverrouillé » est étendu à `KrakenSpotOrderClient` ; « seul `exchange` déclare des méthodes d'ordre » inchangé.
