# Archive

Anciens documents narratifs, conservés pour l'historique mais **jamais à lire comme référence de l'état actuel de l'application**. Ils mélangeaient journal de bord chronologique et affirmations d'architecture, ce qui a produit les conclusions erronées à l'origine du redocumentage du 2026-09-12.

Pour l'état actuel : voir [`../README.md`](../README.md).

## Contenu

- [`README-old.md`](README-old.md) — ancien `README.md` racine du projet.
- [`suivi/`](suivi/) — anciens documents de suivi (`docs/suivi/`) : journal chronologique de points d'avancement, plan de test manuel, état des lieux indicateurs/strategies/opinions.

`docs/etudes/` et `docs/prompts/` n'ont pas été déplacés ici (voir note dans `docs/README.md`) : par construction, ce sont déjà des journaux datés de conception/implémentation, moins susceptibles d'être lus comme une description de l'état courant. Un avertissement a néanmoins été ajouté à la racine de chacun de ces deux dossiers.
