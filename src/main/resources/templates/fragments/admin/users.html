Utilisateurs et accès VPS (tunnel SSH)

Crée un compte TradeIO (rôle utilisateur, mot de passe généré, affiché une seule fois) et, en option, l'accès VPS de l'ami : compte Linux sans aucun droit, tunnel vers l'application uniquement. Désactiver ou supprimer l'utilisateur coupe aussi son accès VPS. Sans le provisioning SSH activé sur le serveur, l'accès VPS est simulé (dev).
