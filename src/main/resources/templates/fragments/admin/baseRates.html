Taux de base par actif
N'influence pas les ordres. Ces montants servent uniquement à proposer le « montant de base » quand un utilisateur relie un actif à son wallet : montant proposé = taux du profil × cash alloué au lien. L'utilisateur peut toujours le modifier.

Saisie en dollars par jour pour 1 000 USDC de cash. Plus le montant est grand, plus le cash est dépensé vite (plus d'exposition, plus de baisse possible). Un profil plus offensif ne peut pas avoir un montant plus faible : Prudent ≤ Équilibré ≤ Dynamique ≤ Full. Un actif sans ligne propre affiche les valeurs de repli (celles du BTC) : enregistrer crée sa ligne dédiée.

Sans effet sur les ordres : mémorise la marge avec laquelle ces montants ont été calés (perte maximale tolérée ÷ k). Si vous changez les montants, mettez k à jour pour garder la trace.
